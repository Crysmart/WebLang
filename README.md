# Frontend Learning

一个用于学习前端主流框架的示例项目集合。

## 📚 项目列表

### 1. hello-electron
Electron 桌面应用学习项目

**技术栈：**
- Electron
- TypeScript
- Electron Forge

**快速开始：**
```bash
cd hello-electron
npm install
npm start
```

### 2. hello-react
React 框架学习项目

**技术栈：**
- React
- Create React App

**快速开始：**
```bash
cd hello-react
npm install
npm start
```

### 3. hello-vue
Vue.js 框架学习项目

**技术栈：**
- Vue 3
- Vue Router
- Babel

**快速开始：**
```bash
cd hello-vue
npm install
npm run serve
```

## 📂 目录结构

```
workspace
├── hello-electron/     # Electron 桌面应用
├── hello-react/       # React 单页应用
└── hello-vue/         # Vue 3 示例应用
```

## 🎯 学习内容

- **hello-electron**: 桌面应用开发、Electron IPC 通信、预加载脚本
- **hello-react**: 组件化开发、React Hooks、状态管理基础
- **hello-vue**: 组合式 API、组件通信、路由配置、生命周期
